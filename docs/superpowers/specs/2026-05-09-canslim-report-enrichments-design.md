# CANSLIM Report Enrichments — 2026-05-09

Add three CANSLIM-aligned signals plus a model-attribution footer and a
search-language guardrail to the daily report.

## Scope

1. **ROE** (CANSLIM "L" support): show `info["returnOnEquity"]` in the
   snapshot table; **bold when > 17%** (IBD's leadership floor).
2. **Institutional Sponsorship** (CANSLIM "I"): aggregate quarter-over-
   quarter holder activity from `Ticker.institutional_holders` —
   `X added / Y reduced / Z new` over the current top-N holders. Zero
   persistence (no historical state required).
3. **Bold growth highlights** (CANSLIM "C"): bold the Latest Quarter row
   segments when:
   - Revenue YoY > 20%  → bold the `Revenue $X (YoY +Y%)` segment
   - EPS YoY > 25%      → bold the `EPS $X (YoY +Y%)` segment
   Same thresholds applied to the **rightmost (most recent) cell** of the
   4-quarter YoY tables.
4. **Web-search language guardrail**: update `prompts/canslim_system.md`
   to direct the model — for US tickers — to ground qualitative analysis
   in **English-language professional outlets** (Bloomberg, Reuters,
   WSJ, FT, CNBC, Barron's, Seeking Alpha PRO/quant pages, company IR /
   SEC filings). Chinese-language sources should not be the primary
   citation for US-listed stocks. HK tickers retain the existing freedom
   (Chinese sources are appropriate for HK names).
5. **Model attribution**: each report ends with a single line —
   `Generated by <model-id> (<vendor>)` — e.g.
   `Generated by claude-sonnet-4-6 (Anthropic)` or
   `Generated by deepseek-v4-flash (DeepSeek)`. The backend already
   knows; we expose `backend.model_label()` and the renderer prints it
   in the footer.

## Data Schema (`report/enrich.py`)

Two new fields in the per-ticker dict (and in `_EMPTY_DATA_TEMPLATE`):

```python
"roe_pct": None,                    # float | None — % (37.76 not 0.3776)
"inst_holder_activity": None,       # dict | None — see below
```

`inst_holder_activity` shape when populated:

```python
{
    "added": int,        # holders with pctChange > 0
    "reduced": int,      # holders with pctChange < 0
    "new": int,          # holders with NaN pctChange (first-time entries)
    "total": int,        # rows in the institutional_holders table
}
```

If the DataFrame is empty / missing / API error: stays `None`. Skipped
for HK tickers (yfinance `institutional_holders` is US-only-reliable).

## Bold rendering (`report/renderer.py`)

The latest-quarter snapshot line currently renders as plain text:

```
**Latest Quarter:**  EPS $0.42 (YoY +90.9%)  ·  Revenue $90.1M (YoY +54.4%)
```

Apply bold to either side independently when its YoY exceeds the
threshold. Markdown bold (`**...**`) for `.md`; the `<strong>` HTML
mirror is already produced by the markdown renderer pipeline.

For 4-quarter YoY tables, bold the rightmost numeric cell when over
threshold. Implementation: a small helper `_fmt_yoy_cell(value, threshold,
is_latest=False)` that returns `**+X.X%**` when `is_latest and value >
threshold` else `+X.X%` / `—`.

## Footer

Single line at the very bottom of the markdown body and HTML page:

```
*Generated by claude-sonnet-4-6 (Anthropic) · 2026-05-09*
```

## Out of Scope

- Historical institutional ownership trend (would require persistence —
  defer to a follow-up if needed).
- Per-quarter ROE history (snapshot only is sufficient for CANSLIM "L").
- Chinese-source enforcement at the tool-call level (we instruct via
  prompt; we don't filter Tavily results post-hoc).
